Terme und Graphen zuordnen

Gebrochen-rationale Funktionen, Jahrgangsstufe 13

Woran du dich orientierst

1. Asymptote: Grade vergleichen

  • Zählergrad < Nennergrad: waagrechte Asymptote y = 0
  • Zählergrad = Nennergrad: waagrechte Asymptote y = c mit c ≠ 0
  • Zählergrad = Nennergrad + 1: schräge Asymptote (Polynomdivision)

2. Definitionslücken: Nenner = 0

  • Lässt sich der Linearfaktor kürzen: hebbare Lücke (offener Kreis)
  • Sonst Polstelle. Ungerade Vielfachheit: mit Vorzeichenwechsel, gerade Vielfachheit: ohne Vorzeichenwechsel

3. Nullstellen: Zähler = 0

  • Nur Stellen zählen, an denen die Funktion definiert ist
  • Ungerade Vielfachheit: Graph schneidet die x-Achse, gerade Vielfachheit: er berührt sie nur

So geht's: Wähle links einen Term aus und klicke dann auf den Graphen, der dazu passt. Am Computer kannst du den Term auch auf den Graphen ziehen. Mit „Überprüfen“ bekommst du Rückmeldung: Richtige Zuordnungen werden festgehalten und erklärt, bei falschen gibt es Hinweise.

Alle Graphen zeigen den Ausschnitt −6 ≤ x ≤ 6 und −6 ≤ y ≤ 6. Ein offener Kreis markiert eine Stelle, an der die Funktion nicht definiert ist.
